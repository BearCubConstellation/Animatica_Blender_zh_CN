# 验证说明

验证环境：Windows、Blender 5.1.2、Animatica 0.7.0-preview3、汉化包 1.0.0。

## 已验证

1. 单元测试覆盖显示文字与用户数据分离、错误详情保留、枚举标识保留、模块范围限制、字体代理隔离、无效占位符回退、加载钩子幂等、适配编译失败回退和官方注解语义，共 9 项。
2. 独立 Blender 用户配置中注册两插件，检查 RNA 属性名称、提示词保留、自绘占位文字及官方更新地址。
3. 使用官方更新器 `_swap` 对临时副本进行同版本目录替换；独立汉化包保留，已收录文字显示中文，新增测试文案显示英文。
4. 禁用并重新启用官方插件；切换汉化开关；三个独立 Blender 进程分别验证中文、英文、中文。
5. 独立 GUI 配置中检查主要面板、浮动工具栏、时间轴及插件设置。截图不使用用户工作文件。
6. 原工作环境中的 133 个官方文件内容哈希不变，排除 `__pycache__`。

## 范围限制

- 模拟更新使用同版本源码替换，不代表未来新版本已通过兼容测试。
- 未下载新版本、未升级工作环境、未调用云端动作生成。
- 字体测量测试覆盖多种字号，GUI 截图只验证所使用的窗口尺寸和缩放；不保证所有显示器与 DPI。
- 词库 1124 条；静态扫描识别 1096 条并全部命中。运行时构造的未知文本、服务端内容和原始错误详情可能保留英文。
- 限定模块及字体代理隔离有自动化验证，但未逐一检查用户安装的全部第三方插件。
