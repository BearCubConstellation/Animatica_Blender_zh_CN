# 验证说明

当前验证环境：Windows、Blender 5.1.2、Animatica Choreographer 1.0.4、汉化包 1.1.0。

## 已验证

1. 13 项单元测试：显示文字与用户数据分离、错误详情保留、枚举标识保留、模块范围限制、字体代理隔离、无效占位符回退、加载钩子幂等、编译失败回退、官方注解语义、全部词库占位符一致性、新版剪贴板提示、引导说明与角色计数、内部就绪原因保持不变。
2. 使用官方 v1.0.4 Release ZIP 中的源码扫描，895 条识别文案全部命中，未出现扫描错误。词库共 1530 条，保留旧版译文以兼容既有安装。
3. 从最终汉化 ZIP 解包到系统临时目录，注册两插件，检查 RNA 属性名称、提示词保留、自绘占位文字、私有字体代理和官方更新地址。
4. 调用真实官方更新器 `_swap`，验证 1.0.4 同版本替换，以及 0.7.0-preview3 → 1.0.4 跨版本替换。新版本正常加载，汉化仍生效，独立汉化包保留，新增未知测试文案按原文显示。
5. 检查 1.0.4 折叠工具栏、复制/粘贴动作的中文标签，以及折叠按钮的中文工具提示。
6. 切换汉化开关并重载官方插件；三个独立 Blender 进程分别验证中文、英文、中文，Blender 全局语言保持 `en_US`。
7. 官方新旧版来源目录在测试前后的文件哈希一致，排除 `__pycache__`。未更改用户工作配置。
8. 打包检查全部词库的格式占位符；ZIP 使用固定时间戳，同一源码可重复生成相同 SHA-256。英文固定文件名与带版本号中文文件名的 ZIP 字节相同。

## 重现

```powershell
python -m unittest discover -s tests -p "test_core.py" -v
python tools/build.py --tag v1.1.0
python animatica_zh_cn/check_missing.py "新版/animatica_blender" "coverage.json"
python tools/validate_blender.py --blender "Blender路径/blender.exe" --addon "新版/animatica_blender" --package "dist/Animatica_zh_CN.zip"
python tools/validate_blender.py --blender "Blender路径/blender.exe" --addon "新版/animatica_blender" --previous-addon "旧版/animatica_blender" --package "dist/Animatica_zh_CN.zip"
```

Blender 测试环境位于系统临时目录，日志和 JSON 报告写入工程 `.work/`，不提交个人路径或用户配置。GitHub Actions 运行单元测试和打包；Blender 集成验证需另外运行。

## 范围限制

- 跨版本验证使用预先取得的官方文件调用真实目录替换函数，未测试联网检查或下载更新，也未调用云端生成。
- 本轮未重新执行 GUI 实拍验收。README 截图来自此前 0.7.0-preview3，与 1.0.4 布局可能不同；不保证所有窗口尺寸和 DPI。
- 扫描覆盖率仅表示扫描器能识别的文案。运行时构造的未知文本、服务端内容和原始错误详情可能保留英文。
- 官方 1.0 起将手动编辑拆分为独立 Animatica Marionette；本包适配范围仍限定于 `animatica_blender`，不覆盖 Marionette 内部模块。
- 尚未验收其他系统、Blender 版本或所有第三方插件组合。
